
# Titanic Data Journey — D100 Ex 4

## Overview
This project refactors a Titanic Kaggle Jupyter Notebook into reusable Python modules following software engineering best practices.

## Project Structure
- `Titanic Data Journey.ipynb` — Main analysis notebook
- `src/data_utils.py` — Data loading and inspection
- `src/features.py` — Feature engineering
- `src/visualization.py` — Data visualisation
- `src/model.py` — Random Forest training and evaluation
- `pixi.toml` — Environment dependencies
- `pixi.lock` — Resolved dependency versions

## Setup
1. Clone the repository.
2. Install pixi if it is not already installed.
3. Run `pixi install`.
4. Open the notebook in VS Code.
5. Select the project's pixi Python environment as the Jupyter kernel.
6. Run the notebook cells in order.

## Analysis
The notebook includes:
- Data inspection and missing-value analysis
- Exploratory data analysis
- Feature engineering
- Random Forest baseline classification
- Training and validation evaluation

Development is organised using Git feature branches, pull requests and code reviews.
